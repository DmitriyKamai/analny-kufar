# Анальный куфар

Бот для мониторинга объявлений [Kufar](https://www.kufar.by): периодически опрашивает search API, находит новые объявления по вашим запросам и присылает их в Telegram.

Реализация — **Python** (`notifier.py`) с управлением через **inline-кнопки**.

> Только для ознакомительных целей. Если вы представляете администрацию Kufar и у вас есть претензии к проекту — откройте Issue.

---

## Возможности

- Несколько пользователей: у каждого свои поиски и свой кэш объявлений
- Доступ по паролю (`/start` → пароль)
- Настройка поиска кнопками: запрос, регион, цена, лимит, интервал опроса
- Уведомления с фото, ценой, датой и ссылкой
- Без внешних pip-зависимостей (стандартная библиотека Python 3.10+)

## Быстрый старт

### 1. Требования

- Python **3.10+**
- Telegram-бот от [@BotFather](https://t.me/BotFather) (токен)

### 2. Конфиг

Создайте или отредактируйте `kufar-configuration.json`:

```json
{
    "telegram": {
        "bot-token": "123456:TELEGRAM_BOT_TOKEN"
    },
    "access-password": "change-me",
    "delays": {
        "query": 10,
        "loop": 1800
    },
    "users": {}
}
```

| Поле | Описание |
|------|----------|
| `telegram.bot-token` | Токен бота |
| `access-password` | Пароль при `/start` |
| `delays.query` | Пауза между поисковыми запросами (сек), по умолчанию для новых пользователей |
| `delays.loop` | Пауза между полными циклами опроса (сек) |
| `users` | Данные пользователей (заполняется ботом автоматически) |

Файл `cached-data.json` хранит уже отправленные `ad_id` **по каждому пользователю**. Вручную править обычно не нужно. Минимальный вид:

```json
{}
```

### 3. Запуск

Из папки проекта:

```bash
python notifier.py
```

или с явными путями:

```bash
python notifier.py --config="./kufar-configuration.json" --cache="./cached-data.json"
```

Полезные флаги:

| Флаг | Назначение |
|------|------------|
| `--once` | Один проход по поискам и выход |
| `--dry-run` | Не отправлять сообщения в Telegram |

На Windows удобно запускать с небуферизованным выводом:

```powershell
python -u notifier.py
```

### 4. Первый вход в Telegram

1. Найдите своего бота и отправьте `/start`
2. Введите пароль из `access-password`
3. Откроется меню с кнопками

## Управление в Telegram

### Команды

| Команда | Действие |
|---------|----------|
| `/start` | Вход (пароль) или главное меню |
| `/menu` | Главное меню |
| `/list` | Список поисков |
| `/add …` | Быстро начать черновик (`/add велосипед`) |
| `/status` | Статус |
| `/logout` | Выйти (снова нужен пароль) |

### Кнопки меню

- **Мои поиски** — список и удаление
- **Добавить** — создать поиск
- **Интервалы** — период полного цикла (5 / 15 / 30 / 60 мин)
- **Статус** — число поисков, размер кэша, паузы
- **Выйти** — сброс авторизации

### Создание поиска

1. **Добавить** → прислать ключевое слово  
2. Опционально: **Регион**, **Цена до** (кнопки или ввод числа), **Лимит**  
3. **Сохранить**

Уведомления приходят в тот же чат, где настроены поиски.

## Как это работает

```
/start + пароль
      ↓
пользователь добавляет поиски
      ↓
watcher раз в N секунд:
  для каждого авторизованного пользователя
    → запрос к Kufar search API
    → новые ad_id (нет в кэше пользователя)
    → сообщение в Telegram
    → запись id в кэш
```

Поисковый endpoint (неофициальный, как у сайта):

```
https://searchapi.kufar.by/v1/search/rendered-paginated
```

Основные параметры запроса:

| Параметр API | Откуда | Смысл |
|--------------|--------|--------|
| `query` | `tag` | Ключевое слово |
| `size` | `limit` | Сколько объявлений за раз |
| `ot=1` | `only-title-search` | Только заголовок |
| `prc` | `price` | Диапазон цены в копейках |
| `rgn` | `region` | Регион |
| `ar` | `areas` | Районы (`v.or:1,2,3`) |
| `sort` | `sort-type` | `prc.d` / `prc.a` |

Регионы: `1` Брест … `7` Минск.

Бот берёт **первые `limit` объявлений** из выдачи Kufar. При старте процесса и при добавлении поиска текущая выдача **запоминается без уведомлений** — в чат приходят только объявления, появившиеся после этого.

Дата в сообщении: `ДД.ММ.ГГГГ, ЧЧ:ММ` (UTC+3).

Номер телефона продавца search API **не отдаёт** (только флаг «скрыт/не скрыт»). Чтобы позвонить, откройте ссылку на объявление.

## Безопасность

- Не публикуйте `bot-token` и пароль
- Смените `access-password` на свой
- Пароль общий для всех пользователей бота: кто знает пароль — может пользоваться
- Храните конфиг только у себя; при утечке токена отзовите его у BotFather

## Устранение проблем

**`Conflict: terminated by other getUpdates request`**  
Запущен второй экземпляр бота. Оставьте только один процесс `python notifier.py`.

**Бот не отвечает на кнопки**  
Проверьте, что процесс запущен и в логе есть `[BOT]: polling Telegram updates...`.

**Нет новых уведомлений**  
- Пользователь авторизован и есть поиски в «Мои поиски»  
- Объявление новое для *вашего* кэша  
- Оно попадает в топ `limit` результатов API  

**Пустая выдача**  
Проверьте фильтры (категория/регион/цена). Неверная категория даёт ноль результатов.
